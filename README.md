# MegaGrid
## A Unity game prototype featuring minimalist platforming with a twist: moving color waves across platforms.

The goal is to navigate across a grid of platforms (consists of blue and green platforms which are safe to cross) while also dodging the incoming wave of red unsafe platforms spawning in any row and/or column.

The player starts with 3 lives, and the timer for the level is randomized between 30 and 60 seconds. Each time the player touches the red platform, the number of lives decrements by one. Once no more lives are left, then the game is over, and the level restarts. Once the timer reaches zero, the player can touch the green platform to win the level.

Controls: WASD and/or arrow keys to move, and spacebar to jump over platforms
